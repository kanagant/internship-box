# The tracker Sheet

Create one Google Sheet named "Internship Inbox" in the student's Drive, after they say yes. Keep the header row exactly
as below so later syncs can find the right columns.

| Column | What goes in it |
| --- | --- |
| Company | The company's name |
| Role | The role title, or blank |
| Stage | Applied, Assessment, Interview, Offer, Rejected or Unclear |
| Next step | Short, for example "Online assessment" or "Video interview" |
| Next date and time | The time with its time zone, or blank |
| Last email | The date of the newest related email (YYYY-MM-DD) |
| Source | The email's subject line, so the student can search for it |
| Notes | Left for the student; this Skill never edits or deletes it |

Rules:

- One row per company and role. Update the existing row instead of adding a duplicate.
- Update only rows this Skill created, found by company and role. Never delete rows or clear the Notes column.
- Sort so the nearest next date is first, and keep Rejected rows at the bottom.
- Keep Source to the subject line only. Do not paste email bodies into the Sheet.
